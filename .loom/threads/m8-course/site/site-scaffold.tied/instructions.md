# Eleventy scaffold

- Eleventy with Markdown content under `course/` (one file per week, plus
  syllabus, appendices and a home page).
- Layouts: home, module, appendix, whole-course reader.
- Navigation: week list, previous/next, in-page contents.
- No analytics, no external fonts or scripts, no trackers. Works with
  JavaScript off.
- `npm run build` and `npm run serve` documented in the README.
