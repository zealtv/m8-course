# Visual design and components

- Typography and layout that read well for long study sessions, in light and
  dark themes, and at phone width.
- Components, as Eleventy shortcodes: tracker grid (phrase, chain, song,
  table), instrument patch sheet, FM algorithm diagram (original SVG),
  exercise box, rubric table, key-press notation, callouts.
- Each component follows the conventions in `docs/module-template.md`.
